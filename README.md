This is the text editor I made for Lab 7.
I apologies in advance for the terrible code.

to make or edit a file just:

```./editor filename```

Controls:
- ARROW KEYS
- Backspace (delete)
- Enter (newline)
- Any key (for typing duh)
- CTRL + r (replace character under cursor)
- CTRL + f (find character in line after cursor) (Filtering is sort of like sifting through data)))
- CTRL + s (save file, but it will save automatically if you close the window)
